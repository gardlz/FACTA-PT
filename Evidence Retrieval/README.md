# Evidence Retrieval

This directory contains the code used to evaluate **question-driven evidence retrieval for fact-checking in European Portuguese**. It compares three ways of querying the LUSA News Corpus: the **complete claim**, the **claim span**, and **verification questions** generated by the 14 language models evaluated in the [Question Generation](../Question%20Generation/) stage.

The experiments assess whether automatically generated verification questions improve the retrieval of relevant evidence relative to declarative queries. The LUSA search infrastructure is kept fixed; the experiment studies **query formulation**, not alternative retrieval models. Only news published **before the source claim's publication date** is eligible.

## Experimental overview

| Component | Description |
|---|---|
| Document collection | The **LUSA News Corpus**: 1,346,032 documents (about 1.3M) published by Agência Lusa between 1 January 2016 and 20 April 2026, searched through a fixed hybrid API that fuses BM25 over headline and content with `intfloat/multilingual-e5-large` semantic search through Reciprocal Rank Fusion. |
| Evaluation set | The fixed **100 CLEVER test claim spans** used in question generation. |
| Question-based queries | Predictions from 14 models fine-tuned with **Gold91+Silver1073**. |
| Query baselines | Complete claim and claim span, searched separately. |
| Retrieval configurations | **Single-search top-5:** one query (the first generated question for question-based retrieval). **RRF top-5:** merge the results of all generated questions using Reciprocal Rank Fusion, retaining five documents. **Matched retrieval volume:** retain the distinct documents obtained from all generated questions, with the declarative baselines evaluated at a comparable claim-span-specific retrieval volume. |
| Evaluation | Relevant and Decisive **Macro/Micro Recall**, **Decisive Claim-Span Coverage (DCSC)**, and retrieved documents per claim span (**Docs/span**). |

The reference evidence comes from CLEVER's manually annotated LUSA documents. Evaluation covers **83 claim spans** with Relevant evidence, **56** with decisive (Supported or Refuted) evidence, and **54** with a unique decisive ground-truth status for DCSC.

The commands in run order, the inputs of each step, the evaluation definitions and the complete result tables are in [Reproducing the experiments](docs/REPRODUCIBILITY.md).

## Repository structure

```text
src/
  build_gold_questions.py           Prepare CLEVER question/query inputs
  retrieve_lusa.py                  Retrieve ranked LUSA results
  lusa_api.py                       Restricted API client
  dedup_versions.py                 Consolidate reissued LUSA articles
  comparar_queries.py               Retrieval metrics of every query strategy and configuration
  bootstrap_emparelhado_queries.py  Paired bootstrap confidence intervals of the differences
  comum.py                          Shared data paths and utilities
docs/REPRODUCIBILITY.md             Commands in run order and the complete result tables
requirements.txt                    Pinned Python dependencies
```

Some file names and command-line values are in Portuguese: `frase` denotes the **complete claim**, and `--query claim` searches the **claim span**.

## Data and access

**Datasets and LUSA news content are not included in this repository.** Obtain CLEVER following the [main repository instructions](../README.md#data) and the applicable access conditions. Paths below are relative to `Evidence Retrieval/`:

```text
../CLEVER/clever.json                  # CLEVER, with the gold questions and the evidence annotations
data/export_evidencias/evidencias.csv  # Top-5 results of every search of every condition
outputs/lusa_top20_claim/              # Ranking of each claim span
outputs/lusa_top20_frase/              # Ranking of each complete claim
outputs/lusa_docs/                     # Cached LUSA documents
```

The stored retrieval files include restricted LUSA material and are **not redistributed**; they may be requested from the authors subject to the LUSA News Corpus access conditions.

Accessing the search API requires an **institutional VPN** and an uncommitted `.env` file in this directory containing `API_URL_LUSA`, `USER_LUSA`, and `PASSWORD_LUSA`. Never commit credentials.

## Installation

Run from `Evidence Retrieval/`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The code runs on **CPU**; no GPU is required.

## Running the experiments

From `Evidence Retrieval/`, with CLEVER available, prepare the query inputs and retrieve the **gold-question**, **claim-span**, and **complete-claim** rankings:

```bash
python src/build_gold_questions.py

# Requires LUSA API access (VPN and credentials)
python src/retrieve_lusa.py
python src/retrieve_lusa.py --query claim --output-dir outputs/lusa_top20_claim
python src/retrieve_lusa.py --query frase --output-dir outputs/lusa_top20_frase
```

`build_gold_questions.py` writes `outputs/gold_questions.jsonl`, one query unit per CLEVER gold question, with its claim span, complete claim and publication date. The three `retrieve_lusa.py` calls search with the gold questions, the claim spans and the complete claims, and write one ranking file per search to `outputs/lusa_top20/`, `outputs/lusa_top20_claim/` and `outputs/lusa_top20_frase/`, respectively, caching the retrieved documents in `outputs/lusa_docs/`. The CLEVER reference documents were collected from the gold-question searches, so the gold questions are not an evaluated condition.

With the **stored retrieval results** listed above available locally, compute the experiment tables and paired bootstrap analysis offline:

```bash
python src/comparar_queries.py
python src/bootstrap_emparelhado_queries.py
```

The metric report is written to `outputs/comparacao_queries.md`, and bootstrap outputs to `outputs/bootstrap/`.

## Main results

The following values are from **Matched retrieval volume**, which retains the distinct candidates retrieved through multiple verification questions. Higher is better except for Docs/span, which measures retrieval volume rather than quality.

| Query | Relevant Macro R | Relevant Micro R | Decisive Macro R | Decisive Micro R | DCSC | Docs/span |
|---|---:|---:|---:|---:|---:|---:|
| Complete claim | 0.209 | 0.235 | 0.255 | 0.286 | 0.352 | 9.0 |
| Claim span | 0.241 | 0.309 | 0.314 | 0.402 | 0.407 | 9.0 |
| Gervásio-8B PT-PT questions | 0.351 | 0.382 | 0.415 | 0.420 | 0.519 | 9.0 |
| **AMALIA-9B-0626-DPO questions** | **0.370** | **0.387** | **0.445** | **0.464** | **0.593** | 8.9 |

AMALIA recovered at least one decisive reference document consistent with the reference status for **32 of the 54** DCSC evaluation cases, compared with **22 of 54** for the claim span. Its DCSC improvement over the claim span was **+0.185** (paired bootstrap 95% CI: **[0.056, 0.315]**). Relative to the complete claim, the paired differences in all five metrics have intervals that exclude zero; relative to the claim span, the intervals for Relevant and Decisive Micro Recall include zero.

Taking into account both intrinsic question quality, evaluated in the [Question Generation](../Question%20Generation/) stage, and downstream retrieval performance, **AMALIA-9B-0626-DPO** was selected for the FACT-PT pipeline. The fine-tuned model is available at [liaad/facta-pt-qg-amalia-9b-0626-dpo](https://huggingface.co/liaad/facta-pt-qg-amalia-9b-0626-dpo).

The complete 14-model comparison, the results for all three retrieval configurations and the paired bootstrap differences are in [Reproducing the experiments](docs/REPRODUCIBILITY.md#results), which also gives the composition of the ground truth and the LUSA News Corpus statistics.
